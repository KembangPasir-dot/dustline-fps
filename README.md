DUSTLINE is a round-based tactical FPS in the style of Counter-Strike, built with three.js. Fight 5v5 against bots on the Dustline Yard map — a desert-industrial compound with Site A warehouse, Site B silos, and a mid-lane — first to 5 rounds wins, by elimination or bomb plant/defuse. It has a buy-menu economy, five fictional weapons, a full HUD, pointer-lock mouse look, and procedural WebAudio sounds. No build step; three.js 0.187.0 is vendored.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser with WebGL 2.
